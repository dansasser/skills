# Security policy

Skills can include executable code and instructions that use your account's permissions. Review a skill and its requirements before running it. Runtime resource limits are not a security sandbox.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/dansasser/skills/security/advisories/new) for vulnerabilities in this repository. Include the affected skill, version or commit, reproduction steps, likely impact and any proposed fix. Remove credentials and personal information from the report.

Use ordinary [GitHub Issues](https://github.com/dansasser/skills/issues) for non-sensitive bugs and usage questions. Do not disclose exploitable details, credentials or private data in a public issue.

## Versions

Security fixes are applied to the current maintained source. Check the [changelog](CHANGELOG.md) and the relevant skill's documentation when updating. This project does not promise a response deadline or maintenance for every historical tag.
